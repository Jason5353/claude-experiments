## Guessing Game

A simple command-line game where the computer picks a random number between
1 and 100, and you try to guess it.

### Requirements

- Python 3

### How to run

```bash
python3 guessing_game.py
```

Enter a number when prompted. The game will tell you if your guess is too
high or too low, and reports how many guesses it took once you find the
correct number.
